# Abdalla Elmorsi - Scripts and Code Reference

PowerShell, Bash, Python, and Arduino code referenced across posts on [abdallaelmorsi.net](https://www.abdallaelmorsi.net), organized by topic. Each file links back to the post it came from, which has the full explanation, prerequisites, and context.

These are reference scripts meant to be read and adapted, not run blind against a production environment. See the linked post for what each one assumes about your environment before using it.

## Categories

- [`active-directory/`](active-directory/) - AD compromise tracing, LAPS, Group Policy, domain services
- [`automation/`](automation/) - Monitoring alert scripts, agentic automation patterns
- [`cloud-computing/`](cloud-computing/) - Azure and OCI setup and administration
- [`exchange/`](exchange/) - Exchange Server incident response, mailbox administration
- [`linux/`](linux/) - systemd troubleshooting, Windows-to-Linux command reference
- [`microsoft/`](microsoft/) - Microsoft Graph PowerShell, MFA auditing, Windows Server, certificates
- [`robotics/`](robotics/) - Arduino and Raspberry Pi project code
- [`virtualization/`](virtualization/) - Hyper-V and VMware setup

## Usage

Every script here is also embedded, with full explanation, in its source post. Use `index.json` at the repo root to map any file back to its originating post URL.
